# Andrew's Logistics — PM Training Course

Interactive preventative maintenance training for heavy-duty trucks and tanker trailers.

## Files
- `index.html` — the full interactive course (open this in a browser)
- `PM_Training_Video.mp4` — Fleetrock walkthrough video (must stay in the same folder as index.html)
- `images/` — all course images (must stay in the same folder as index.html)

## Hosting
Deploy the entire contents of this folder to Netlify (drag and drop) or any static web host.
The `index.html` file must be in the root with the `images/` folder and video file alongside it.
